# Phase 5 Arrange Report
## 目的
MVPのUI/UXを、残心らしい静けさ・余白・現代和の方向へ磨き込み,体験も独自に最大化する。

## 改善した内容
- 和紙感を強めるため、背景に淡い質感レイヤーと控えめな奥行きを追加し、全体の第一印象を静かに調整
- ヘッダー、検索、一覧カード、空状態、新規作成ボタンの余白・階層・タップ感を見直し、iPhoneでの視認性と操作性を改善
- エディタの行間・入力余白・操作ボタンの触り心地を調整し、本文入力を主役にした書く体験へ磨き込み

## 変更した主なファイル
- src/index.css
- src/components/AppShell.tsx
- src/components/NotesList.tsx
- src/components/NoteCard.tsx
- src/components/SearchBar.tsx
- src/components/EmptyState.tsx
- src/components/NoteEditor.tsx

## デザイン判断
過剰な装飾を避けつつ、和紙の柔らかさ・余白・静かなコントラストを中心に調整しました。  
視線がタイトル→検索→カード→入力へ自然に流れるように、情報密度を下げ、間を広げています。  
また、各操作のactive/hover/focusを控えめに揃えて、触り心地を統一しつつ入力体験を邪魔しない設計にしています。

## 守ったこと
- 複雑にしすぎない
- 余白を守る
- 侘び寂びを意識する
- iPhone-first
